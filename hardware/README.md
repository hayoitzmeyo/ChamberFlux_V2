# Hardware files

Add the finalized release files here:

- `stl/` - printable mesh files
- `3mf/` - oriented print projects
- `step/` - neutral editable CAD exports
- `source/` - Onshape link and/or native source exports

Recommended release naming:

- `OCF_Base_v1.0.stl`
- `OCF_DualFanCarrier_v1.0.stl`
- `OCF_Base_v1.0.step`
- `OpenChamberFlow_v1.0.3mf`

Include version numbers so users can identify compatible parts.
